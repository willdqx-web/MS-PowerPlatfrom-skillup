## 0. 今日のゴール

これから12日間かけて、あなたは「手作業でやっている業務を、自分で自動化できる人」になります。
その初日である今日は、**自分のパソコンの中だけで完結する自動化**から始めます。
クラウドもライセンスも関係なく、すぐに動かせるところから慣れていきましょう。

今日の業務シナリオは「**散らかった受信フォルダの片付け**」です。
設計補助の現場では、図面・検討書・帳票が 1 つのフォルダにどんどん溜まっていき、
「種類ごとにフォルダを分けて、バックアップも取る」という単純だが面倒な作業が発生します。
これを Power Automate Desktop（以下 PAD）で自動化します。

- PAD の画面構成と「アクションを並べる」という考え方を理解する
- レコーダー（操作の記録機能）で、自動化が動く体験をする
- 変数・条件分岐・繰り返しを PAD で書ける（VBA の知識をそのまま活かします）
- フォルダ内のファイルを取得し、条件に応じて振り分け・コピーできる

まず1章を読んでから、2章以降のステップ演習に進んでください。

## 1. 機能・概念の解説

### 1-1. Power Automate Desktop（PAD）とは

**パソコンの操作を自動化するツール**です。マウス操作・キーボード入力・ファイル操作・
アプリの起動などを、「アクション」と呼ばれる部品を上から順に並べることで自動化します。

VBA マクロを書いたことがあるなら、考え方はほぼ同じです。違いは**コードを書かないこと**だけです。

| | VBA マクロ | PAD |
|---|---|---|
| 処理の書き方 | コードを文字で書く | **アクションをドラッグして並べる** |
| 動かせる範囲 | 基本は Office の中 | **パソコン全体**（ファイル・ブラウザ・他アプリ） |
| 変数 | `Dim i As Integer` | 変数ペインで自動的に管理される |
| 繰り返し | `For Each` / `Do While` | 「For each」「Loop」アクション |
| 分岐 | `If ... Then` | 「If」アクション |
| 実行場所 | Excel の中 | **自分の PC 上**（PC が動いている必要がある） |

> **今日いちばん大事な感覚**: PAD は「VBA のコードを、部品の並べ替えで書くもの」です。
> 新しい概念を覚えるというより、**すでに知っていることの書き方が変わるだけ**だと思ってください。

### 1-2. PAD の画面構成

PAD でフローを開くと、画面が大きく 3 つに分かれています。

| エリア | 場所 | 役割 |
|--------|------|------|
| **アクションペイン** | 左 | 使える部品（アクション）の一覧。ここから中央にドラッグする |
| **ワークスペース** | 中央 | 処理を並べる場所。ここが「マクロの中身」にあたる |
| **変数ペイン** | 右 | 処理の途中で使われている値の一覧。デバッグのときに見る |

### 1-3. 変数と「%」の書き方

PAD では、変数を使うときに **`%` で囲みます**。これだけ覚えれば大丈夫です。

| やりたいこと | 書き方 |
|--------------|--------|
| 変数 `FileCount` の中身を使う | `%FileCount%` |
| 文字と変数をつなげる | `合計 %FileCount% 件でした` |
| 変数の中の項目を使う | `%CurrentItem.Name%` |

> **なぜ `%` が要るのか**: PAD は「ただの文字」と「変数の中身」を見分ける必要があります。
> `FileCount` と書くとそのまま文字として扱われ、`%FileCount%` と書くと中身（例: 18）に
> 置き換わります。Excel の数式で `"合計"` と `A1` を区別するのと同じ理屈です。

### 1-4. レコーダー（操作の記録）

自分がマウス・キーボードで行った操作を**そのまま記録して、アクションに変換してくれる機能**です。
Excel の「マクロの記録」とまったく同じ発想です。

便利ですが、注意点もあります。

- ✅ 向いていること: 手順が決まっている単純な操作、とりあえず動くものを作る
- ⚠️ 苦手なこと: 画面のレイアウトが変わると壊れやすい。条件分岐や繰り返しは記録できない

**実務では「レコーダーで大枠を作り、あとから手で整える」**という使い方が基本です。

### 1-5. ファイル操作の考え方

今日使う主なアクションは次のとおりです（左のアクションペインの「ファイル」「フォルダー」内）。

| アクション | 何をするか |
|------------|-----------|
| フォルダー内のファイルを取得 | 指定フォルダのファイル一覧を取り出す（結果は「リスト」型の変数） |
| ファイルの移動 | ファイルを別フォルダへ移す |
| ファイルのコピー | ファイルを別フォルダへ複製する（元は残る） |
| ファイルの名前を変更 | ファイル名を変える |
| フォルダーの作成 | 新しいフォルダを作る |

「フォルダー内のファイルを取得」で得られる変数は**リスト（複数件の入れ物）**です。
VBA でいう配列やコレクションと同じで、`For each` で 1 件ずつ取り出して処理します。
1 件ずつ取り出したものには、次のような情報が入っています。

| 書き方 | 意味 | 例 |
|--------|------|-----|
| `%CurrentItem%` | ファイルのフルパス | `C:\...\P001_図面_20260601.pdf` |
| `%CurrentItem.Name%` | ファイル名（拡張子つき） | `P001_図面_20260601.pdf` |
| `%CurrentItem.Extension%` | 拡張子 | `.pdf` |

## 2. ステップ演習1: 演習フォルダの準備と PAD の起動（目安30分）

### 2-1. 演習用のダミーファイルを作る

1. このフォルダの `day1_ダミーファイル生成.ps1` を**右クリック**する
2. 「**PowerShell で実行**」をクリックする
   → 黒い画面が一瞬出て、作成完了のメッセージが表示されます
3. デスクトップに `PAD演習_Day1` フォルダができ、その中の `01_受信フォルダ` に
   **18 個のファイル**が入っていることをエクスプローラーで確認する

> 実行できない・警告が出る場合は、スクリプトを右クリック →「プロパティ」→ 下部の
> 「セキュリティ: 許可する」にチェック → OK してから、もう一度試してください。
>
> **やり直したくなったら**: このスクリプトをもう一度実行すれば、いつでも初期状態に戻ります。
> 演習中に失敗しても大丈夫です。安心して試してください。

#### 確認用の答え合わせ（`01_受信フォルダ` の中身）
| 種別 | 拡張子 | 件数 |
|------|--------|------|
| 図面 | .pdf | 8 |
| 検討書 | .docx | 5 |
| 帳票 | .xlsx | 5 |
| **合計** | | **18** |

### 2-2. PAD を起動して最初のフローを作る

1. Windows のスタートメニューから「**Power Automate**」を検索して起動する
   （見つからない場合は Microsoft Store から「Power Automate」をインストールする）
2. 会社のアカウントでサインインする
3. 「**新しいフロー**」をクリックし、フロー名を `Day1_練習` として作成する
   → フローの編集画面（1-2 で説明した 3 分割の画面）が開きます
4. 左のアクションペインで「メッセージ ボックス」→「**メッセージを表示**」を、
   中央のワークスペースにドラッグする
5. 「表示するメッセージ」に `はじめてのフローです` と入力して「保存」をクリック
6. 画面上部の「▷（実行）」をクリックする
   → メッセージボックスが表示されれば成功です

### 2-3. 変数を使ってみる

1. アクションペインで「変数」→「**変数の設定**」を、先ほどのメッセージ表示の**上**にドラッグする
2. 変数名を `MyName`、値に自分の名前を入力する
3. 下の「メッセージを表示」をダブルクリックし、メッセージを
   `%MyName% さん、はじめてのフローです` に書き換える
4. 実行する → 自分の名前が入ったメッセージが出れば OK
   （`%` で囲むと中身に置き換わることを確認してください）

## 3. ステップ演習2: レコーダーを体験する（目安30分）

自動化が「勝手にできあがる」感覚をつかみます。

1. 新しいフロー `Day1_レコーダー練習` を作成する
2. 画面上部の「**レコーダー**」をクリックする
3. 記録が始まったら、次の操作をゆっくり行う
   - メモ帳を起動する
   - `テスト入力` と文字を打つ
4. レコーダーの「**停止**」を押し、「完了」をクリックする
   → 自分がやった操作が、アクションとしてワークスペースに並んでいます
5. メモ帳を閉じてから、フローを「▷（実行）」する
   → メモ帳が自動で起動し、文字が自動で入力されれば成功です

### 気づいてほしいこと

- 記録されたアクションを**1 つずつ読んでみてください**。「アプリを起動」「キーを送信」など、
  自分の操作が部品に翻訳されているのが分かります。
- ただし、この記録には「もしファイルが無かったら」「10 回繰り返す」といった判断はありません。
  **判断や繰り返しは、次章のように自分で組む必要があります。** これがレコーダーの限界です。

## 4. ステップ演習3: ファイル一覧を取得して繰り返す（目安60分）

ここからが本題です。`01_受信フォルダ` の中身を PAD に読ませます。

1. 新しいフロー `Day1_ファイル整理` を作成する
2. アクションペインで「フォルダー」→「**フォルダー内のファイルを取得**」をドラッグする
3. 設定する
   - フォルダー: `01_受信フォルダ` を指定（右のフォルダアイコンから選択できます）
   - ファイル フィルター: `*`（すべてのファイル）
   - 生成された変数: `Files`（既定のままで OK）
4. 「保存」→「実行」する
5. 右の**変数ペイン**で `Files` をダブルクリックする
   → 18 件のファイルが一覧で入っていることを確認する（ここが確認のコツです）

### 4-1. 繰り返しで 1 件ずつ処理する

1. アクションペインで「ループ」→「**For each**」をドラッグする
2. 設定する
   - 反復処理を行う値: `%Files%`
   - 保存先: `CurrentItem`（既定のまま）
3. 「For each」と「End」の**間に**、「メッセージを表示」をドラッグして入れる
4. メッセージに `%CurrentItem.Name%` と入力する
5. 実行する
   → ファイル名が 1 件ずつ、18 回表示されます（毎回 OK を押してください）

> 18 回 OK を押すのは大変ですが、「**リストの中身を 1 件ずつ取り出せている**」ことを
> 体感するための確認です。次の手順でメッセージ表示は削除します。

### 4-2. 件数を数える（変数の練習）

1. さきほどの「メッセージを表示」を右クリック → 「削除」
2. 「For each」の**前**に「変数の設定」を置き、変数名 `Count`、値 `0` にする
3. 「For each」の**中**に「変数」→「**変数を大きくする**」を置き、
   変数名 `Count`、大きくする数値 `1` にする
4. 「End」の**後ろ**に「メッセージを表示」を置き、`ファイルは %Count% 件です` と入力する
5. 実行する

#### 確認用の答え合わせ
- 表示されるメッセージ: **`ファイルは 18 件です`**

## 5. ステップ演習4: 種類ごとにフォルダへ振り分ける（目安60分）

いよいよ実用的な処理です。拡張子を見て、図面・検討書・帳票を別フォルダに移します。

### 5-1. 振り分け先フォルダを作る

フローの**先頭**に、「フォルダー」→「**フォルダーの作成**」を 3 つ置きます。

| 新しいフォルダー名 | 作成先 |
|--------------------|--------|
| `図面` | `PAD演習_Day1\02_整理済` |
| `検討書` | `PAD演習_Day1\02_整理済` |
| `帳票` | `PAD演習_Day1\02_整理済` |

> `02_整理済` フォルダ自体が無い場合は、先に「フォルダーの作成」で `PAD演習_Day1` の下に
> `02_整理済` を作るアクションを追加してください（合計 4 つになります）。

### 5-2. 条件分岐で振り分ける

「For each」の中に、次のように組みます。

1. 「条件」→「**If**」をドラッグして For each の中に置く
   - 最初のオペランド: `%CurrentItem.Extension%`
   - 演算子: `と等しい(=)`
   - 2 番目のオペランド: `.pdf`
2. If の中に「ファイル」→「**ファイルの移動**」を置く
   - 移動するファイル: `%CurrentItem%`
   - 宛先フォルダー: `02_整理済\図面`
3. 同じ要領で、`.docx` → `検討書`、`.xlsx` → `帳票` の If をもう 2 つ作る
   （If を 3 つ縦に並べる形で構いません）
4. 保存して実行する

#### 確認用の答え合わせ（実行後のフォルダ）
| フォルダ | 件数 |
|----------|------|
| `02_整理済\図面` | 8 |
| `02_整理済\検討書` | 5 |
| `02_整理済\帳票` | 5 |
| `01_受信フォルダ` | 0（空になる） |

> うまくいかなかったら、`day1_ダミーファイル生成.ps1` を再実行して初期状態に戻し、
> もう一度試してください。**やり直せることが、自動化を学ぶ上でいちばん大事な安心材料です。**

## 6. 応用課題（自力で取り組んでください）

ここからは手順の細かい指示はありません。1〜5 章を活かして、自分で考えて取り組んでください。
取り組む前に `day1_ダミーファイル生成.ps1` を再実行し、初期状態に戻してから始めてください。

1. **バックアップを取ってから振り分ける**
   振り分け（移動）を行う前に、`01_受信フォルダ` のファイルをすべて
   `03_バックアップ` フォルダへ**コピー**する処理を追加する。
   （ヒント: 「ファイルのコピー」アクション。移動と違い、元のファイルが残ります）

2. **案件コード別に振り分ける**
   種別（拡張子）ではなく、**ファイル名の先頭の案件コード**（`P001` など）ごとの
   フォルダに振り分けるフローを作る。
   （ヒント: ファイル名から先頭 4 文字を取り出すには「テキスト」→「テキストの部分文字列を取得」を使います）

3. **処理結果をテキストファイルに残す**
   処理したファイル数を、`PAD演習_Day1\処理ログ.txt` に書き出す。
   （ヒント: 「ファイル」→「テキストをファイルに書き込む」）

4. **（任意・発展）** 対象フォルダが空だった場合に「対象ファイルがありません」と表示して
   終了するようにする。エラーで止まらない自動化にするための第一歩です。

## 7. 保存方法（今日の成果物）

提出物は、同梱の **`提出物作成.bat`** が 1 枚のレポートに自動でまとめます。次の順で進めます。

### 手順

1. **フローのテキストを保存する**
   提出するフロー（`Day1_ファイル整理`。応用課題まで反映したもの）を編集画面で開き、
   ワークスペースをクリック → **Ctrl + A** → **Ctrl + C** → メモ帳に **Ctrl + V** で
   貼り付け、**デスクトップの `PAD演習_Day1` フォルダの中**に `Day1_ファイル整理.txt`
   という名前で保存する。
   - 複数のフローを提出したい場合は、`Day1_練習.txt`・`Day1_応用課題.txt` のように
     いずれも先頭を `Day1_` にして、同じフォルダに保存する（ツールがまとめて拾います）。

   > **なぜテキストなのか**: このテキストは、**別の PAD に貼り付ければフローとして復元できます**。
   > レビューする側もアクションの並びをそのまま読めるため、画像より正確に確認できます。
   > PAD のフロー一覧を右クリックしてもファイル出力（エクスポート）の項目はありません。
   > テキストとしてコピーするのが、標準的なフローの受け渡し方法です。

2. **提出物作成.bat を実行する**
   このフォルダ（教材と同じ場所）にある `提出物作成.bat` をダブルクリックする。
   氏名を入力すると、デスクトップに **`提出_Day1_氏名.txt`** が作られる。

3. この **`提出_Day1_氏名.txt` 1 枚を提出する**（スクリーンショットは不要）。

> このレポートには、整理後のフォルダ構成・各フォルダの件数・処理ログ・フローのテキストが
> すべて含まれます。件数が期待どおりか（図面 8 / 検討書 5 / 帳票 5 など）も自動でチェックされ、
> 「要確認」と出た項目があれば提出前に見直せます。
